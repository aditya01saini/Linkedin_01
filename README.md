# 🔗 LinkedIn Clone Application

A full-stack **LinkedIn Clone** web application built to replicate core features of LinkedIn such as user authentication, profile management, posts, and a modern responsive UI.

## 🚀 Features

- 🔐 User Authentication (Login / Register)
- 👤 User Profile (Bio, Image, Details)
- 📝 Create & View Posts
- 🖼️ Image Upload Support
- 📰 Feed System
- 📱 Fully Responsive Design
- ⚡ Fast & Optimized UI
